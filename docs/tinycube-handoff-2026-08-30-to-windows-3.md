## 4. まだ残っていること

### (2) の穴（前の手紙にも書きました）

**イベントが1つも飛ばず、かつ画面も切り替わらないまま**トラックが死ぬと、
いまの作りでは気づけません。`visibilitychange` に加えて
**設定画面から撮影画面へ帰るときにも `readyState` を確かめる**と塞がります。
仕様上そうはならないはずなので、**急ぎではありません。**

### 動画の道の「戻る」

戻るとフレームの一覧ではなく効果の面に戻り、枠を選び直す道がすぐには
見つかりません（写真の道では一覧に戻ります）。
面が分かれているだけかもしれないので、**意図どおりならこのままで。**

### `_facePerf.mjs`

上の理由（GPU を待っていない／canvas を canvas に描いている）で 0 しか
出ません。`_fps.mjs` があるので、**消すか置き換えるかはそちらで。**

## 追記 — ビルド7 は選べませんでした。ビルド8 を出し直しました

**私の見落としです。** App Store Connect のバージョンの枠は 1.5.3 のまま
（`READY_FOR_REVIEW`、2026-08-25 作成）でした。

⚠️ **枠の番号と一致するビルドしか選べません。**
　　ビルド6 は 1.5.5、ビルド7 は 1.5.6 なので、1.5.3 の枠には**出てきません。**
　　伊波さんが「ないよ」と言ったのはこれです。

枠の番号を 1.5.6 に変える手もありましたが、掲載情報に触ることになるので、
**こちらの版を枠に合わせました。**

```
  ビルド 8   1.5.3   VALID   ← いまここ。今日の直しが全部入っている
  ビルド 7   1.5.6   VALID   ← 枠が無いので選べない
  ビルド 6   1.5.5   VALID   ← 同上
  ビルド 5   1.5.3   VALID   ← 古い。2.1(b) の直しも入っていない
```

⚠️ **1.5.3 の枠には、ビルド5 と 8 が並んで出ます。**
　　どちらも版は 1.5.3 なので、**ビルド番号 8** で見分けてください。

⚠️ **iOS と Android の版がずれました**（iOS 1.5.3 / Android 1.5.6）。
　　リポジトリの `project.pbxproj` も 1.5.3 / 8 に戻してあります。
　　次に揃えるときは、**先に App Store Connect の枠を作るか番号を変えてから**
　　ビルドの版を上げること。逆にすると、また選べないビルドができます。
