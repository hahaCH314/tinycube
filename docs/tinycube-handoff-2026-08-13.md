## 0. 最初に読んで — ここで3回ハマった

### ⚠️ CSS は `src/setup.css` に書く。他の2つは効かない

CSS が3か所にあって、**実際にブラウザへ届くのは `setup.css` だけ**。

| ファイル | 実態 |
|---|---|
| `src/App.css` | **どこからも import されていない。** さらに `vite.config.ts` がビルドのたびに上書きする。ここに書いても消える |
| `docs/tinycube-skin-shibuya.css` | スキンの原本。App.css の生成元だが、App.css 自体が読み込まれないので**間接的にも効かない** |
| **`src/setup.css`** | **`App.tsx` が import している。ここだけが効く** |

私はこの順に3回書き直した。**同じ道をたどらないこと。**
`grep -rn "\.css" src/main.tsx src/App.tsx` で、読み込まれているものを先に確かめる。

（`index.css` も `main.tsx` から読まれているが、70行の色の定義だけ）

### ⚠️ サービスワーカーが古い CSS を握る

直したのに画面が変わらないときは、まずこれを疑う。`public/sw.js` がキャッシュしている。
検証時は毎回これを消していた：

```js
await win.webContents.session.clearCache();
await win.webContents.session.clearStorageData({ storages: ['serviceworkers','cachestorage'] });
```

ロゴの隣に出ている読み込み時刻（`LOADED_AT`）は、**まさにこれを見破るための印**。
実機で「変わらない」と言われたら、その時刻が動いているか聞くこと。

### ⚠️ `dist/index.html` を `file://` で開いても真っ白

アセットが `/assets/...` の絶対パスなので、`file://` では解決しない。
検証は必ず HTTP で：`cd dist && npx http-server -p 4173 --silent`

### ⚠️ Electron が固まったら、残ったプロセスを疑う

検証を何度も回すと `electron.exe` が溜まって、次の起動が無言で固まる。
`taskkill //F //IM electron.exe //T` で一掃してから再開する。

### グリッチ → ミラーボール

90年代ディスコ。ヒマワリさんが絵を決めた（A案「光の粒が回りながら流れる」／🪩／**音なし**）。

⚠️ **`drawMirrorball` を書くとき、2回失敗した。**
粒を28個ぜんぶ**1つの角度から出すと、必ず1本の斜め線に並ぶ**。
どう散らし方を工夫しても直らない。本物のミラーボールは高さの違う輪が何本もあって
輪ごとに大きさも速さも違うので、**7本の輪に分けて**ようやく散った。
`effects.ts` の `spotAt` に、同じ罠の注意書きを残してある。

絵文字の玉突きも起きた：🪩 は元々フラッシュが使っていた → フラッシュを 📷 に移した →
**下バーの「写真」と被った**（伊波さんの指摘）→ フラッシュは 💥 に落ち着いた。

### C. 録画後の確認画面 ←【最優先・一番大きい】

**まだ手つかず。** いまの `save()` は無言で `a.click()` を叩いていて、
利用者が止める隙がない。

- `screen` に `'done'` を足して、`onFinish` は保存せず blob を持って done へ
- 「保存する」「やり直す」の2つ。やり直すは **`video` に戻す**（設定に戻さない）
- ⚠️ **保存先フォルダは選ばせられない。** File System Access API は iOS Safari に無い。
  「ダウンロードフォルダに入ります」と文字で伝え、`navigator.canShare` が
  使える端末だけ「写真に保存」（Web Share）を出す
- ⚠️ `URL.revokeObjectURL` を必ず呼ぶ。やり直しを繰り返すとメモリに溜まる
- ⚠️ **`save()` に触るので、壊れると「録れたのに残らない」という一番痛い壊れ方をする。**
  単独でコミットすること

⚠️ **`docs/tinycube-update-scope.md` の「即保存 UX」は、今日の指示で覆っている。**
scope 側の書き換えがまだ済んでいない。**次に読む人が逆の実装をしないよう、直すこと。**
