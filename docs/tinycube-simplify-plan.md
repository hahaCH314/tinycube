# tinyCUBE かんたん化 — 実装プラン

**このファイルの役割**：2026-08-13 の伊波さんの指示「CMCUBE の複雑な操作を省く」を、
実装できる単位に割ったもの。**上書きして最新1枚に保つ**（追記しない）。

- 対象ユーザー：**40〜50代と子どもたち**。使いやすさ優先の誘導線とボタン配置
- 今どうなっているかは [`tinycube-ground-truth.md`](./tinycube-ground-truth.md)
  ⚠️ **ground-truth は 8/12 時点で古い。** setup.css / sounds.ts / idb.ts / unlock.ts など、
  そこに載っていないものが実装済み。このプランは `src/` の実物を読んで書いた
- 何を作るかの全体は [`tinycube-update-scope.md`](./tinycube-update-scope.md)

## 0. 先に — 方針がひとつ覆ります

scope 1章の **「4. 即保存 UX：録画終了後、プレビューを挟まず即保存して終わり」は、
今日の指示で無効になりました。**

> 今日の指示：**勝手に保存しない。撮り終わったらどこに置くか誘導する。
> やり直しのボタンも作る。**

伊波さんに確認済み（2026-08-13）。**scope 側の該当箇所は、この実装と同時に書き換える。**
古い記述が残っていると、次に読んだ人が逆の実装をします。

理由づけとしても筋が通っています：**対象が40〜50代と子ども**なら、
「気づいたら保存されていた」より「保存しますか／撮り直しますか」のほうが安心できる。

## 1. 何を減らすのか（現状 → 目標）

| ところ | いま | これから |
|---|---|---|
| 左レール（音） | **15個**（効果音10＋自作枠2＋エフェクト3） | **6個**（音3＝拍手・ドラム・電子音／**エフェクト3はそのまま残す**） |
| 音ファイル読み込み | あり（`my1`/`my2` に自分の音を入れられる） | **廃止** |
| 右レール（テキスト） | **12個**（自分の3＋決め打ち9） | **5個**（全部ユーザーが変更できる） |
| 録画後 | 即ダウンロード（`save()` が無言で `a.click()`） | **確認画面**（保存する／やり直す） |
| フレーム選択 | タイルを押すと即決定。見えるのは小さいタイルだけ | **小窓に大きめのプレビュー**を出す |
| 設定画面 | 1画面に7セクション縦積み | **1画面1設定**に分ける |

## 2. タスク（実装順）

依存の少ないものから並べています。**上から順に、1つずつコミットできる**単位です。

### A. 音を3つに絞る ＋ 音ファイル挿入を廃止

**触るファイル**：`src/effects.ts` / `src/App.tsx` / `src/sounds.ts` / `src/i18n.ts`

⚠️ **エフェクト3つ（`flash` / `glitch` / `emotional`）は残します**
（2026-08-13、伊波さん「エフェクトは残していいよ」）。減らすのは**音だけ**。
`flash` は動画に光を差し込む唯一の手段なので、消すと戻せる場所がなくなります。

1. `effects.ts` の `EffectId` を **音3つ＋エフェクト2つ＋`telop`** にする
   - 残す：`'clap' | 'drum' | 'blip'`（音）／ `'flash' | 'glitch'`（エフェクト）／ `'telop'`
   - 消す：`bam` / `ding` / `pon` / `buzz` / `dread` / `slash` / `fanfare` / `my1` / `my2`
   - `emotional` は `EffectId` ではなく `setAmbient('emotional')` の別枠。**触らない**
   - `DUR` テーブルからも消す。**消し忘れると型は通るが押しても無音になる**
2. `sounds.ts` を **ファイルごと削除**。IndexedDB の `sounds` ストアも使わなくなる
   - `SOUND_SLOTS` / `loadSaved` / `setCustom` / `clearCustom` / `customName` / `customBuffer`
     の**呼び出しが `App.tsx` に6か所ある**。全部消す
   - `effects.ts` の `useCustomSounds` / `getCustom` も道連れで消える
   - ⚠️ **すでに音を入れている人の IndexedDB は残る。** 消さなくても害はないが、
     気になるなら1回だけ削除する後始末を入れる（優先度は低い）
3. `App.tsx` の左レール（`data-role="sound"`）を **6個**に書き直す
   - 上に**音3つ**（`btn-sound`）、下に**エフェクト3つ**（`btn-burst`）。
     いまと同じ並び順（エフェクトは柱の下、2026-08-11 の指示）をそのまま保つ
   - 自作枠（`btn-mine` の `my1`/`my2`）だけを消す。
     `soundVer` / `soundSlot` / `soundInputRef` / `onSoundFile` も不要になる
   - ⚠️ **15個→6個でレールがすかすかになります。** いまの高さ計算は15個前提
     （ground-truth 4章：横向きは2列に逃がしている）。**6個なら1列で収まるので、
     横向きの2列分岐は不要になるはず**。ボタン1つを大きくできる余地でもあります
4. 設定画面の「効果音」セクション（`sound-list`／`sound-row`）を**まるごと削除**
5. `i18n.ts` から、消した音のラベルを削除

**確認のしかた**：3つとも押して鳴ること。**録画に混ざること**（耳で鳴っても動画に
入らないことがある。`recDest` を通っているかが要点）。

### B. テキストを5つにして、全部ユーザーが変えられるようにする

**触るファイル**：`src/App.tsx`

いまの作りは「自分の3つ＋決め打ち9つ＝12個」。これを**5つ全部が自分のもの**にします。

1. `TELOP_MINE` を **3 → 5**
2. `TELOP_FIXED`（`'やば'`〜`'は？'` の9個）を**削除**。`telops` は `myTelops` そのもの
3. 初期値を5つ入れておく（**空にしない**。指示は「テキストは予め入っている」）
   - 例：`['マジ？', 'かわいい', 'ちゅき', 'やば', '最高']` ← **文言は伊波さん決め**
4. `localStorage` の `tinycube.telops` は**キーを変える**（`tinycube.telops.v2` など）
   - 変えないと、前の3つぶんの配列が読まれて4・5番目が初期値に戻る事故が起きる
5. 右レールのボタンは5つとも `number-icon`（番号1〜5）にする。
   `BUBBLE` / `ZIGZAG` の出し分けは不要になる
6. 設定画面の入力欄（`telop-inputs`）も5行に増える。**ここが「誘導線」の本体**
   - 撮影画面のテキストボタンを長押し／空タップで、この入力欄へ飛べるようにする
     （いまも空のときだけ `openSetup('video')` が呼ばれている。**5つとも**そうする）

### C. 撮り終わったあとの確認画面（勝手に保存しない）

**触るファイル**：`src/App.tsx`（`save()` と `onFinish`）

**ここが今日の指示の中で一番大きい変更**です。いまの `save()` は
`a.click()` を無言で叩いていて、利用者が止める隙がありません。

1. 新しい画面 `screen === 'done'` を足す（`'agree' | 'manner' | 'setup' | 'video' | 'done'`）
2. `onFinish` は**保存せず**、blob を state に持って `setScreen('done')` するだけにする
   ```
   録画停止 → done 画面
     ├ 「保存する」  → いまの save() を呼ぶ
     └ 「やり直す」  → blob を捨てて video 画面へ戻る
   ```
3. **保存先の誘導**：ブラウザは保存先を指定できないので、
   **「ダウンロードフォルダに入ります」と文字で伝える**のが正解です
   - ⚠️ **File System Access API（保存先を選ばせる）は iOS Safari に無い。**
     対象がスマホなら使えません。**PC だけ対応、は分岐が増えるのでおすすめしません**
   - 代わりに **Web Share API** があると、iPhone は「写真に保存」が選べます。
     `navigator.canShare({ files })` が使える端末だけ「写真に保存」ボタンを出す
4. done 画面には**プレビューを出す**（`<video>` に blob URL）。
   ⚠️ scope 2章の「シェア画面・プレビュー画面を足さない」は
   **0章のとおり今日の指示で無効化されました**。scope を書き換えること
5. blob の後始末：`URL.revokeObjectURL` を必ず呼ぶ。
   やり直しを繰り返すとメモリに溜まります

**やり直しボタンは撮影画面にもすでにあります**（`preview-btn-round` の `↺`、
[`App.tsx:839`](../src/App.tsx#L839)）。ただし**いまは `setup` に戻ります**。
done 画面の「やり直す」は **`video` に戻す**（設定はやり直したくないはず）。
ここは2つの `↺` の行き先が違うので、**アイコンか文字で区別する**こと。

### D. フレーム選択に小窓プレビューを出す

**触るファイル**：`src/App.tsx` / `src/setup.css`

いまはタイルを押すと `setFrameId` が即座に変わるだけで、
**選んだものが大きく見える場所がありません**。

1. `.frame-picker` の**すぐ上に固定の小窓**（`.frame-preview`）を置く
   - 中身は選択中のフレーム画像を、タイルより**大きく**表示
   - `f.bgFile` があるフレームは**2枚重ね**（下に bgFile、上に file）。
     タイル側と同じ描き方にする（[`App.tsx:1299-1303`](../src/App.tsx#L1299-L1303)）
2. `position: sticky; top: 0` にすると、**タイルを下までスクロールしても
   小窓が見えたまま**になります。40〜50代・子どもには効きます
3. 縦横で形が変わる（`--tile-ar` と同じ `9/16` ↔ `16/9`）
4. 顔ハメ枠は中央が透過なので、**小窓の背景に薄いチェック柄か人型のシルエット**を
   敷くと「ここに顔が入る」が伝わります（任意）

⚠️ **小窓に実際のカメラ映像を映すのは、この段階ではやらない**。
カメラ起動が設定画面に入り込んで、起動が重くなります。まず静止画で十分。

### E. 設定を1画面1つずつにする

**触るファイル**：`src/App.tsx` / `src/setup.css`

いまの設定画面は**1枚に7つのセクションが縦積み**で、下のほうは誰も見ていません
（フレーム一覧が2か所に分かれているのもそのせい）。

**いまある設定**（A で効果音が消えるので6つ）：
1. フレーム選択 ← **主役**
2. 動画の音（マイク／ミックス／オフ）
3. 縦横
4. テキストの位置（中央／ばらばら）
5. テキストの色（白／黒）
6. テキストの中身（5つ）
7. 買い切り解除

**進め方の案（1つずつ／ステップ形式）**：

```
[1/4] 縦？ 横？        → 大きなボタン2つ
[2/4] フレームを選ぶ    → 小窓つき（D）
[3/4] 文字を決める      → 5つの入力欄
[4/4] 音の設定          → マイク／ミックス／オフ
        ↓
    「この設定で撮る！」
```

- **テキストの位置・色は [3/4] に同居させる**（文字の話なので、離すと迷う）
- **買い切り解除は step から外し、鍵つきフレームを押したときだけ出す**
  （いまも `showUnlock()` がある。**設定の流れに商売を混ぜない**）
- 各ステップに**「もどる」と「つぎへ」**。上に `[2/4]` の進み具合を出す
- ⚠️ **2回目以降は毎回4ステップ踏ませない。** 一度設定した人には
  「フレームだけ選び直す」入口を残すこと。でないと撮り直すたびに苦行になります

**実装は `setupStep` という state 1つ**で足ります。画面を分けるのではなく、
いまの `setup-content` の中を `setupStep` で出し分ける。`.setup-footer` はそのまま使える。

## 3. やらないこと

- **録画の中央（`.stage-canvas`）に何も足さない。** 録画そのもの。ここは不可侵
- **通信先を増やさない。** 製品LPに「Webフォント取得と起動時の更新確認だけ」と
  明記済み。増やすなら先にLPを直す
- **保存先フォルダを選ばせる実装（File System Access API）を、スマホ向けに約束しない。**
  iOS Safari に無い（2章 C-3）
- **左レールのエフェクトを「後で戻せるように」コメントアウトで残さない。**
  消すと決めたなら消す。git に残っています

## 5. 順番と、まとめてよい単位

```
A（音3つ＋ファイル廃止）  ── 独立。すぐ着手できる
B（テキスト5つ）          ── 独立。A と同時でもよい
        ↓
E（設定1つずつ）          ── A・B で減らしてから組み直すほうが手戻りが無い
D（小窓プレビュー）        ── E の [2/4] の中に入るので、E と同時が自然
        ↓
C（録画後の確認画面）      ── 独立だが、一番大きい。単独でコミットする
```

**推奨：A → B →（D＋E）→ C の4コミット。**
C を最後にするのは、`save()` に触るので**壊れると「録れたのに残らない」**という
一番痛い壊れ方をするためです。他が安定してから単独で入れる。

## 6. 検証（実機で必ず確かめること）

推測で「直りました」と言わないための一覧。**売り物なので特に**。

| 何を | どう確かめるか |
|---|---|
| 音3つ | 3つとも押して鳴る。**録画した動画を再生して音が入っている** |
| 音ファイル廃止 | 設定画面のどこにも音のファイル選択が無い。**コンソールにエラーが出ない** |
| テキスト5つ | 5つとも編集できる。**閉じて開き直しても残っている**（localStorage） |
| 確認画面 | 録画停止 → **勝手に保存されない**。保存を押して初めてファイルが出る |
| やり直し | やり直す → 撮影画面に戻る。**前の録画が残っていない** |
| 小窓 | フレームを変えると小窓が変わる。**2枚重ねの枠も正しく重なる** |
| 設定1つずつ | 4ステップを最後まで通れる。**もどるで前のステップに戻れる** |
| 既存の破壊確認 | `docs/shoot.cjs` で 390×844 と 844×390。**クリック可否も見る** |

⚠️ **ビルドは通っても、録画に音が入らない不具合は画面では見えません。**
必ず出来上がったファイルを再生して確かめること。
