## 3. 相談 — `ios/` を git に入れませんか

**いま `ios/` は git に入っていません。** Mac のローカルにしかない状態です。

私の手元（Windows）から `ios/` が見えないので、
**iOS 側で何が起きているかを、コミットの説明からしか知れません。**
それ自体は困らないのですが、気になっているのは別のことです。

⚠️ **Mac が壊れたら、iOS のビルド設定が全部消えます。**
　　署名の設定、Info.plist の文言、課金の設定、`cap add ios` 後に手で
　　直したところ。作り直すのは大変なはずです。

入れる場合、**そのまま入れてはいけないものがあります。**

- `ios/App/Pods/`（CocoaPods が落としてくるもの。重いし再生成できる）
- `ios/App/App.xcodeproj/xcuserdata/`（各自の画面の状態）
- 署名の秘密鍵や `.p12`（**絶対に入れない**）

`.gitignore` に上の3つを足したうえで `ios/App/App.xcodeproj/project.pbxproj`
と `Info.plist` を入れれば、設定は守れます。

**判断はそちらに任せます。** Mac の事情はそちらの方が分かっているので。

## 4. まだ手つかず — カメラのカクつき

伊波さん「前から重い」「外で撮影使用中に感じる」（2026-08-27）。

⚠️ **私は原因を突き止められませんでした。**
　　手元の Chrome では色味もミラーボールも 75fps 出てしまい、
　　**実機の重さが再現できません。**

怪しいと思っているところだけ書きます。

**canvas が 1920x1080 のまま**（`recorder.ts` の `SIZES`）。
スマホの画面は 411px ほどなのに、**その5倍の細かさで毎コマ描いています。**
録画には必要ですが、**撮っていないときは要りません。**

8/19 に一度「カメラが重い」を直したとき（versionCode 41）も、
`g.filter` の理由として「1920x1080 の全画素に計算が走る」を挙げていました。
**大きさ自体は当時から変わっていません。**

「外で」というのも手がかりだと思います。端末が熱くなると処理が絞られます。

⚠️ **ここは録画に関わる場所です。** 撮影中に大きさを変えると録画が壊れます。
　　実機で測れる人が、確かめながら触るべきだと思います。
