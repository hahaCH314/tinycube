## 1. この日に入れたもの（大きい順）

### 写真の道を丸ごと新設

「なにを撮る？」で写真と動画に分かれる。写真は
**3枚連写 → らくがきスタンプ（文字）／デコ（絵） → できあがり確認 → 保存**。

動画とは順番が逆で、**撮ってから飾る**（動画は飾ってから撮る）。

- 連写は毎回「1 / 3」「2 / 3」「3 / 3」と数字を出す。
  **数えずに光らせるだけだと、3回光っても2回に見える**（伊波さんの指摘で判明）
- 保存は3枚を縦に並べて1枚に。コマの形は**撮った写真の形に合わせる**。
  縦で撮ったものを 16:9 の横長コマへ押し込むと顔の上下が切れて顔ハメが台無しになる

### 飾りは指で操る

- 指1本 … つまんで移動
- **指2本 … ひねって傾け・広げて大きさ**（`ptrsRef` と `gestureRef` で実装）
- **ゴミ箱まで運んで離すと捨てる**

つまみ（傾きのスライダー、大きさの小さく／大きく）は**全部外した**。
指でできることをボタンでも用意すると、どちらを使うか迷うため。

### 録画のあとに確認を出す

**止めた瞬間に黙って保存する動きをやめた。**「撮れました！」で撮った動画を
その場で再生し、「やりなおす」「この動画を保存する」の2択にした。
声が入っているかをここで確かめられる。

### 写真の高さ（`max-height`）は下げすぎない

`.photo-screen .shot-big` の `max-height` を詰めればスクロールは消せるが、
**15dvh まで縮めたら飾る相手が見えなくなった。**いまは 35dvh（背の低い端末で 26dvh）。
ここを削って0pxを稼ぐのは本末転倒。削るなら操作パネル側から。

### `position: sticky` は外さない

`.shot-big` を sticky にしてある。外すと、下の操作パネルが縦に長いぶん
**写真がスクロールで画面の外へ出る**（実測 y=-292px）。飾る相手が見えなくなる。

### ゴミ箱は写真の外に置く

最初は写真の中に置いたが、**飾りを置きたい場所と重なって意図せず捨てた**。
いまは待機の列の位置に、待機写真より手前に出している。
写真の中に戻さないこと。

### 記号スタンプ（♪ ★）は色を持つ

絵文字は端末まかせで色が変わる（🎵 が暗い青緑になった）。音符と星は
**記号に替えて色を指定**してある。canvas 側でも色を当てないと黒で焼かれるので、
`Extended_Pictographic` で絵文字と記号を見分けている。

### 動画側を壊していないか毎回見る

写真の道を触ると動画の道も巻き込みやすい。この日は毎回これを確かめた：

- 動画ファイルの読み込みが出るか
