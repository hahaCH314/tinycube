# Windows のシオンから、Mac のシオンへ（2026-08-30）

保存の形について、**方針が変わりました。** そこが今日のいちばん大事なところです。

---

## 1. 保存はいつも 4:5 になりました

伊波さん「インスタ用を通常にしようよ」（2026-08-30）。

**端末へ保存すると、常に 4:5 の白い紙に載った形**になります。
保存の選択肢から「インスタ用」は消しました。

- 形も大きさも変えません。**左右に白い余白が出るだけ**です
- そのままインスタに上げられます（縦に長すぎて切られることがなくなる）
- プリクラ帳へは1コマずつ入るので、こちらは通りません

---

## 2. ⚠️ ここは絶対に守ってください

伊波さん「**シールシートのようにできあがるのがよいのであって、
そこは妥協しちゃダメなとこデショ**」（2026-08-30）。

**シールシートとして成り立つ形が本体です。** インスタに合わせて形を変えては
いけません。

私は 8/23 に**それをやってしまいました。** 4:5 に収めるために
`buildPhotoSheet(9/16)` で1コマの縦を詰めていたのです。理由は
「丸ごと収めると 24% まで縮んで白の海に浮かぶ」でした。

結果どうなったか：

- **顔が完全に切れました**（真ん中を残すので、上にある顔から消える。実測 0%）
- 詰めた時点で、もうシールシートの形ではありませんでした

伊波さんのインスタ投稿を見せてもらって気づきました。3枚とも額から上が
ありませんでした。

⚠️ **`buildPhotoSheet` の `maxCellAR` を復活させないでください。**
　　引数は残してありますが、もう誰も渡しません。

⚠️ **「24%」という数字に惑わされないでください。** あれは面積の割合で、
　　**見た目の大きさは変わりません。** 私はこの数字を根拠に形を崩す判断をし、
　　伊波さんに実物を見せて初めて間違いに気づきました。
　　**迷ったら実物を作って見ること。**

## 3. ほかに直したもの

### 秋フレームの見本（8/29 に出した v1.5.5 に入っています）

8/25 に秋の12枚を足したとき、**見本を作り忘れていました。**
一覧が本体（158〜271KB）をそのまま読んでいて、**2.3MB → 0.24MB** になりました。

⚠️ **季節フレームを足すときは、本体と見本を必ずセットで。**
　　`tools/_aki-thumbs.mjs` に作り方を残しました。

### 動画ファイルを読み込めなかった（Android だけ）

`WebChromeClient` を丸ごと差し替えていて、Capacitor の
`onShowFileChooser` が失われていました。iOS は WKWebView が自分で
処理するので影響ありません。

## 4. まだ分かっていないこと

**手元（Windows の Chrome）では実機の重さを再現できません。** GPU が速すぎて、
どう測っても差が出ません（顔フレームの clip を測ったら 0.01ms でした）。
**実機を持っているそちらでしか確かめられません。**

### カメラのカクつき

伊波さん「前から重い」「外で撮影使用中に感じる」「**顔フレームのカメラが
重いのかも**」（2026-08-27〜29）。

顔フレームは普通のフレームと違い、**毎コマ `clip()` で楕円に切り抜いてから
映像を描いています**（`recorder.ts` の 258行目あたり）。
1920x1080 の canvas でやっているので、非力な端末では効くはずです。

伊波さんの見立ては筋が通っていると思います。**顔フレームだけカクつくか**を
実機で見てもらえれば、原因がはっきりします。

### 戻る→フレーム選び直しで固まる

伊波さん「戻るでフレームの選び直しするとかたまるのかも」（2026-08-30）。

3回繰り返しても手元では固まりませんでした（`tools/_reselect.mjs`）。
ただし**再現できていないだけ**かもしれません。
選び直すたびに絵を読み直すので、メモリが足りなくなる可能性があります。

### 横向きの保存

伊波さん「保存の横向きはフレームがないよ。切れてる」（2026-08-30）。

**まだ実物を見せてもらえていません。** 「フレームが無い」のか
「切れている」のかで原因が変わるので、そこから確かめる必要があります。
