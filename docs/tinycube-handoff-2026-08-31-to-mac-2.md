## 2. 実機で見つかったもの（伊波さんの言葉のまま）

### 「全然違う」— 設定の選択肢が1文字ずつ縦に潰れていた

`.shape-switch` は**フレーム決定の縦横タブ以外にも流用されていた**
（「雰囲気」「色み」「撮るボタンの位置」）。そこへタブ用の太い字と 3px の
枠を当てたので、4つ並ぶ「色み」が入りきらず縦に折れていました。

⚠️ **クラスを流用している場所を数えてから、スタイルを当てること。**
   `.shape-switch--mini`（フレーム決定の段）だけに効かせる形に直しました。

### 「写真を撮るの文字は horror だし」

見出しの縁取りを text-shadow で8方向 × 3px 重ねたら、**字の隙間まで黒が
回り込んで滲んだ影絵**になっていました。1.5px まで細くしています。

⚠️ `-webkit-text-stroke` は内側も削るので使わない、というのは前の手紙の
   とおりですが、**代わりの text-shadow も重ねすぎると同じことになります。**

### 「動きのエフェクトも、色味もいらないよ？」→「3つとも消す」

フレームを選ぶ画面に3段も設定が並んで、**主役の一覧を下へ押していました。**
「動き」「色み」「撮るボタンの位置」を外しました。
仕組み（`effects.ts` の `setAmbient` / `setTone`）は残してあるので、
戻すときは git から `opt-row` を戻すだけです。

## 3. 課金まわりを、伊波さんと作り直しました

いちばん時間をかけたところです。

### 「どこから有料か何なのかなにもわからん」

鍵つきを無料の一覧に混ぜて並べていたのが原因でした。

→ **畳める段に分けました。**見出しは
`🔒 推し色キラリフレームセット（53枚ぜんぶ・¥300）`。畳んだ状態から始まります。

⚠️ **この段は「パックの中身を見せる場所」です。**（伊波さん「53枚1パックに
   できないの？」）。上の無料の一覧は「いま使える絵」だけを出しますが、
   こちらは**縦むき26枚・横むき27枚をまとめて53枚**並べます。
   いまの向きに合わない絵は少し薄くして `↻` を付け、**押すと向きも一緒に
   変わる**ようにしました（押しても何も起きないと壊れて見えるので）。

⚠️ 一度「この向きで27枚」と出したら、伊波さんに「27枚？」と聞かれました。
   セットは53枚なのに画面には27枚しか出ていない、という食い違いです。
   **数と表示は必ず突き合わせること。**

### 「少し見えにくいぐらいのフィルターと鍵はつけたら？」

鍵つきのタイルに**斜め線の膜（薄い白＋-45度のしま）と鍵の札**を付けました。
⚠️ **絵は見せます。**灰色にして色を殺すと、何が買えるのか分からなくなります
（8/31 朝の「鍵付きの絵を見せる」がそれ）。

### 「またいつか足したフレームもこの300円で使えるみたいに聞こえるし」

⚠️ **ここは大事なところです。** 文言がこうなっていました。

```
  一度きりの買い物で、あとから足したフレームが全部使えます。
  ✨ これから足すぶんも、追加のお金なしで使えます
```

**一度買えば永久に全部、という約束**になっていて、¥500 の追加フレームを
別に売る方針と食い違います。書き直しました。

```
  鍵つきの53枚が全部ひらきます（縦むき26枚・横むき27枚）。
  月々のお金はかかりません。
  🔓 鍵つきの53枚がひらく（推し色・サイバー・ゴシック・和風・顔ハメ）
  💧 写真の「tinyCUBE」の透かしが消える
```

⚠️ **¥300 で手に入るのは「いま鍵がかかっている53枚」と「透かし消し」だけ。**

### 商品名がつきました

**「推し色キラリフレームセット」**（伊波さんが命名）。英語は `Sparkle Frame Set`。
`unlock_title` / `unlock_buy_app` / `locked_hint` / `paid_section` を
この名前で統一しています。

### 「Mac はスポンサー募集になってる」→「そうね。変えよう」

`unlock_done_note`（**¥300 を買った人にだけ出る画面**）の末尾に
「スポンサーも募集中だよW」／`Also, sponsors welcome :)` が入っていました。

⚠️ **買った直後に、さらにお金の話をすることになります。**
⚠️ **寄付を募っているのは CUBICENGINE のほう。** tinyCUBE は買い切りで、
   収益の立て方が違います。製品どうしで導線を混ぜません。

その1行だけ外しました。前の2行（伊波さんが書いた挨拶）はそのままです。

## 4. AAB を作り直しました

`E:\cmcube\アプリ本体\tinyCUBE-v1.6.0.aab`（versionCode 56 / 1.6.0、署名済み）

⚠️ **`npx cap sync` は「成功」と出ても中身が欠けることがあります。**
   今日1回起きました。dist に 299 ファイル・フレーム 143 枚あるのに、
   同期先が 65 ファイル・58 枚。そのまま bundle したら
   **AAB が 44MB → 17MB**（フレームが85枚消えたアプリ）。エラーは出ません。
   **危うく Play に上げるところでした。**

   出す前に必ず数を突き合わせてください。

```sh
find dist -type f | wc -l                                   # 299
find android/app/src/main/assets/public -type f | wc -l     # 302
ls android/app/src/main/assets/public/frames | wc -l        # 143
unzip -l ...app-release.aab | tail -1                       # 809 files
unzip -l ... | grep -c 'assets/public/frames/'              # 284
```

   欠けていたら `rm -rf android/app/src/main/assets/public` してから
   もう一度 sync。上書きでは直りません。

⚠️ **284 は「フレーム 142 枚 ＋ 見本(thumb) 142 枚」**です。絵が 284 種類ある
   わけではありません（一覧が本体を読むと重いので大小2つ持っている）。
