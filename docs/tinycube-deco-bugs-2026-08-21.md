# デコる（文字・スタンプ）の不具合3つ — 原因まで（2026-08-21）

宛先：ヒマワリさん、そして Mac 側のシオンへ。
書いたのは Windows 側のシオン。**実機を持っていないので、原因は読んで突き止めたところまで。**
確かめていない。そこは触れる人にお願いしたい。

伊波さんからの報告（そのまま）：

```
＊文字絵文字の大きさ変えられない。実際に出来上がりともズレ
＊スタンプは大きく出すぎ？
＊動画時、camera自撮りでは難しいので、ボタンは右にかためる？
```

---

## 1. 大きさが変えられない

### いまどうなっているか

2026-08-14 に**大きさボタンを消した**（伊波さん「デコスタンプも大きさ指でできない？」
「大きさボタン消して」）。いまは**指2本のピンチだけ**が大きさを変える道。
`src/App.tsx` の 1319 行あたり。

```js
if (pts.length >= 2) {
  // ひねって傾ける／広げて大きさを変える
```

### たぶんこれが原因

1本目の指で `setPointerCapture` している（1303 行）。

```js
(e.target as Element).setPointerCapture?.(e.pointerId);
```

**掴んだ要素がその後のポインタを独占するので、2本目の `pointerdown` が
その要素に届かないことがある。** 届かなければ `ptrs` に入らず、`pts.length >= 2`
が成立せず、**ピンチが起きない＝大きさが変えられない**。

文字は字が小さいほど掴む面積が狭い。**2本目を乗せる場所が無い**という
形でも同じことが起きる。伊波さんが「変えられない」と言うのは、
たぶん動かせはするのに大きさだけ変わらない、という状態のはず。

### 直し方の案（未検証）

- `setPointerCapture` をやめて、`window` で拾う（移動はすでに window で追いかけている）
- または 2本目が来たら `releasePointerCapture` する
- **どうしても指2本が安定しないなら、大きさボタンを戻すことも考えていい。**
  消したのは画面を1行短くするためだった。**変えられないより出ているほうがまし**

⚠️ **実機で確かめてから決めてほしい。** ここは iOS と Android で挙動が違う。

## 2. スタンプが大きく出すぎ

### 原因

`src/App.tsx` 1237 行。置いたときの大きさが**文字とスタンプで違う**。

```js
size: kind === 'text' ? 9 : 14,
```

スタンプだけ 14。文字の 1.5 倍で出てくる。

### そして 1 とつながっている

**ピンチが効かないと小さくできない。** だから「大きく出すぎ」がそのまま残る。
1 が直れば、この項目は「好みの調整」に落ちる。

### 直し方の案

14 → 11 くらい。ただし**数字は実機で見て決めてほしい**。
私は画面を見ていないので、ここは勘で言っている。

## 3. 出来上がりとズレる

### いまどうなっているか

画面は CSS（`fontSize: ${d.size}cqw`）、保存は canvas の `fillText`。
**別々の仕組みで描いている**ので、同じ数字でも同じ大きさにならない。

そこを埋めるために定数がある。`src/App.tsx` 33 行：

```js
const DECO_SCALE = 1.68
```

2026-08-16 に入れた（伊波さん「スタンプの文字が出来上がりが小さくなる」）。
当時のコメントにこう書いてある：

```
実測（💖 を置いて、高さ÷幅で比べた）
  画面 16.80% ／ 保存 10.00% → 1.68倍ぶん足りていなかった
```

### たぶんこれが原因

⚠️ **1.68 は「💖 を1個置いて測った値」。**

CSS の `fontSize` に乗る余白は、**字によって違う**。

- 絵文字 … 字の上下に余白が大きい
- 日本語 … 絵文字ほどではない
- 英数字 … さらに小さい

つまり **💖 で合わせた 1.68 は、文字には合わない。**
伊波さんが「文字絵文字の」と両方書いているのは、たぶんこれ。

### 向きが分かった — **保存したほうが大きい**（2026-08-21、伊波さん）

8/16 は「保存が小さい」だったので 1.68 を掛けた。**いまは逆に振れている。**
掛けすぎ。文字については**係数を下げる**。

### 直し方の案

**文字とスタンプで別の係数を持つ。**

```js
const DECO_SCALE_TEXT  = ?    // 文字用。1.68 より小さい値（要実測）
const DECO_SCALE_STAMP = 1.68 // 絵文字用（💖 で測った値。据え置き）
```

測り方は 8/16 と同じでいい。**画面に置いたものと保存したものを並べて、
高さ÷幅で比べる。** 文字（「あ」など）で測り直せば係数が出る。

⚠️ **スタンプ側もズレていないか確かめてほしい。** 伊波さんの報告は
「文字絵文字の」と両方を指しているように読める。💖 以外の絵文字で
測ると 1.68 でも合っていない可能性がある。

### もっと根っこの直し方（大きい変更）

画面も canvas で描けば、そもそもズレない。ただし**デコるの表示・ドラッグ・
ピンチを全部書き直す**ことになる。いまはそこまでする場面ではないと思う。

## 4. 自撮りのとき、**指でカメラが隠れる**

伊波さん「動画時、camera自撮りでは難しいので、ボタンは右にかためる？」
→ 聞き直したら **「自撮りにすると指でカメラが隠れる」**（2026-08-21）。

⚠️ **私は最初これを「親指が届かない」と読み違えた。** そうではなく、
**ボタンを押しに伸ばした指が、インカメラのレンズを塞いでいる。**
映像そのものに指が入る／暗くなる、という話。押しやすさの問題ではない。

### だから「右に寄せる」でいいのか、確かめてほしい

**レンズの位置は端末によって違う。** 上部中央（パンチホール）、左上、
ノッチの中。**右に寄せれば必ず避けられるとは限らない。**

考えられる直し方：

- **下に寄せる** … レンズはほぼ必ず上にあるので、上下で離すほうが確実
- **右に寄せる** … 伊波さんの端末では効くかもしれない。要実機
- **撮影中はボタンを小さく／薄くする** … 触る面積が減れば手も入りにくい

⚠️ **実機を持っている人が、自分の端末のレンズ位置を見て決めてほしい。**
私は画面もレンズ位置も見ていない。

⚠️ **CSS を触るなら `src/setup.css`。`App.css` は読み込まれていない**
（これで3回ハマっている）。
