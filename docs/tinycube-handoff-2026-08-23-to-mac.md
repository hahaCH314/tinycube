## 2. 今日いれたもの（Android で動いている）

### 動画は「撮る前に決める」形になった

伊波さん「動画だと、色々難しいね、エフェクトも初めに選んで、文字の出現も
自動で出す方がやりやすいかも」。

**なぜそうしたか**が大事なので書いておく。もとの相談は
「自撮りにすると指でカメラが隠れる」だった。私は最初これを
**「ボタンが押しにくい」と読み違えて**、レイアウトを組み替えようとした。
そうではなく、**押しに行った指がレンズを塞いで映像に入る**。

だからボタンを動かすのではなく、**撮影中に押す必要そのものを無くした。**

設定の最後の画面（`setupStep === 'telop'`）に3つ足した：

- **動き** … なし / エモい / ミラーボール
- **色み** … なし / あたたかい / つめたい / こい
- **出し方** … じぶんで / おまかせ / じゅんばん

撮影中に残るのは**フラッシュと音3つだけ**。文字の柱は「じぶんで」のときだけ出る。

⚠️ **色味は映像の直後・枠より前に描くこと**（`recorder.ts` の2箇所）。
順番を逆にすると、フレームの絵118枚ぶんまで染まる。

⚠️ **色味は画素を1つずつ触らない。** 上に1枚重ねるだけ。`getImageData` で走査すると
1080p で1コマ 30ms 近くかかり、描画ループが持たない。

### インスタ用の保存

3連は縦で撮ると比 5.19 になり、インスタの上限 4:5 を超えて切られる。
**4:5 の白い紙に置く**だけでは 24% まで縮んで白の海に浮かぶので、
**インスタ用のときだけ1コマの縦を 16:9 に詰める**。これで縦でも横でも 73%。

伊波さんが LINE カメラでやっていたのがこれ（「要は縦がキュッとなってるだけかな」）。

⚠️ **通常の保存とプリクラ帳は一切変えていない。** 2026-08-17 に用紙そのものを
詰めて「可愛くない」と言われた経緯がある。`buildPhotoSheet(maxCellAR)` の
引数を渡すのはインスタ用の道だけ。

### そのほか

- 文字とスタンプを小さめに置く（9→7 / 14→11）。ピンチが効かないので
  「小さくすればいい」という伊波さんの判断
- 保存の係数を文字用（1.2）とスタンプ用（1.68）に分けた
- 「顔ハメ」→「顔フレーム」（29個）
- 問い合わせ先を icloud に統一（privacy.html）

## 5. まだ手つかず

### ピンチで大きさが変えられない（根っこは残っている）

今日は「最初から小さく置く」で回避しただけ。原因は
`startDrag` の `setPointerCapture` が1本目の指でポインタを独占し、
2本目の `pointerdown` が要素に届かないこと。

⚠️ **iOS 実機で触れるようになったら、ここを見てほしい。**
Android と挙動が違う可能性がある。詳しくは
`docs/tinycube-deco-bugs-2026-08-21.md`。

### ボタンコーナー

伊波さんの指定は「ボタンが小さいと押しにくいので、大きさは変えずに
**ボタンコーナー（操作スペース）**を作る」「**縦持ちの時は画面の下部**に配置」。

⚠️ **ここは触らずに残した。** 録画ボタンの位置に、ズーム欄・横フレームの案内・
フレーム一覧の高さが**全部ぶら下がっている**（`setup.css`。z-index 30/40/60/70）。
過去に2回、この辺りを触って壊している（8/13「録画ボタン見えない」、
8/14「お知らせが録画ボタンに被って どちらも見えない」）。

**実機を見ながらでないと、直したつもりで別の被りを作る。**

### CMCUBE の HP のロゴ

会社HPは済んでいる（`logo-dark.jpg` / `logo-small.png`。`LogoBurst.tsx` を読むこと）。
CMCUBE の HP はロゴを置く場所があるかも未確認。

## 6. そして iOS へ

8/21 の手紙の内容はそのまま生きている。要点だけ：

- `ios/` はまだ無い。`npm i @capacitor/ios && npx cap add ios` から
- `docs/ios-src/GalleryPlugin.swift` を `ios/App/App/` へ。**一度もコンパイルしていない**
- `Info.plist` … カメラ・マイク・**写真の追加**（読み取りは書かないこと）
- 課金はコードを触らなくてよい。App Store Connect で `tinycube_unlock_all`（¥300）

**ネイティブ版を出すと iPhone の人の制限が2つ消える。** 動画保存が共有経由なのと、
プリクラ帳が Safari の履歴消去で消えること。それが iOS 対応の理由。
